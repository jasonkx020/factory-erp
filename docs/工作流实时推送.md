# 工作流实时推送与下一岗确认

## 架构

- **DB 权威**：`wf_task` / `notify_inbox` / `notify_outbox`
- **NanoMQ 扇出**：Hub 账号发布；客户端经 `GET /api/v1/notify/mqtt-connect` 领取短期 MQTT JWT
- **HTTP Auth（对齐 freetv）**：
  - `POST /api/v1/mqtt/auth`
  - `POST /api/v1/mqtt/superuser`
  - `POST /api/v1/mqtt/acl`

## 采购闭环推送

1. 采购员确认出码 → `purchase.weigh_confirmed` → 仓管待办（含 `doc_no`、`trace_code`）
2. 仓管确认入库 → `purchase.stocked` → 财务待支付（抄送采购）
3. 财务支付 → `purchase.settle_paid` → 知会采购

采购完成以仓管 `warehouse-confirm` 为准；采购端不可代仓管入库（角色鉴权）。

## 本地 NanoMQ

```bash
docker compose -f deploy/docker-compose.nanomq.yml up -d
```

配置见 `configs/erp.dev.yaml` 的 `mqtt` 段；`nanomq.conf` 回调默认指向 `host.docker.internal:18080`。
