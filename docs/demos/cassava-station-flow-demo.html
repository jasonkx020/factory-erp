木薯粗加工 工序过站 优化方案

重构理论 Demo · 非线上系统

将「任务 → 工单 → 派工 → 报工」收敛为「箱码驱动的工序过站」。 派工仅用于班次授权与返工/顶岗例外。下列演示覆盖产线每一道工位的运转方式、工具、公式与库存副作用。

产线工位

    过站模拟器

    点击「执行下一步」逐步演示本工位动作

    现状：单据驱动

    1. 生产任务 下达计划量
    2. 工单 + 派工 常自动 spawn，现场弱感知
    3. 扫码报工草稿 confirm_pending
    4. 工人确认 后算损耗/利用率
    5. AfterReportWork 计件、出入库、下工序
    6. 另有简易报工旁路，口径易漂

    目标：箱码过站

    1. 班次授权 工序×人员（非每箱派工）
    2. 扫工牌 + 扫箱 + 过磅 一次采集
    3. 确认过站 原子写入损耗/库存/计件
    4. 箱码 current_process 自动前移
    5. 派岗 仅返工/顶岗/月薪责任
    6. 下班核对 当日产量与工资自助确认

    统一公式（全加工工位）

    loss L = max(input I − output O, 0)
    utilization U = O / I  (I > 0)
    piecewage = O × rate  (仅计件工位)
    stock_out = I  |  stock_in / next = O
    入场：净重 = 毛重 × (1 − 扣损率) → 合格入保鲜库
